# Iteration 16 — Эффекты на мяч

## Что изменилось с предыдущей итерации
- Обновлён `BallEffects.cs`:
  - Частицы при ударе флиппером (жёлтые, разлетаются)
  - Искры при отскоке от стен/препятствий (голубоватые)
  - Частицы при голе (золотые)
  - Автоматический OnCollisionEnter2D для отскоков
- Добавлен `BallGlow.cs` — пульсирующее свечение вокруг мяча
- Добавлен editor скрипт `SoccerGameSetup_Iteration16.cs`

## Как настроить
1. Скопируй файлы в проект (заменить BallEffects.cs)
2. Открой Game сцену
3. В Unity: меню **SoccerGame → Setup Ball Effects (Iteration 16)**

## Что создаётся/меняется на сцене
- **Ball / TrailRenderer** — улучшен: ярче (жёлто-оранжевый), длиннее (0.25s), плавнее
- **Ball / Glow** — дочерний объект с мягким пульсирующим свечением

## Настройка в Inspector

### BallEffects (на Ball)
- `Hit Particle Count` — кол-во частиц при ударе (8)
- `Bounce Particle Count` — кол-во частиц при отскоке (4)
- `Particle Speed` — скорость разлёта (5)
- `Particle Lifetime` — время жизни частиц (0.4)

### BallGlow (на Ball/Glow)
- `Pulse Min / Max` — диапазон пульсации прозрачности (0.3–0.6)
- `Pulse Duration` — скорость пульсации (0.8s)

### TrailRenderer (на Ball)
- `Time` — длина следа (0.25)
- `Start Width` — ширина начала (0.3)

## Как тестировать
1. Нажми Play
2. Мяч светится мягким пульсирующим светом
3. Trail за мячом — яркий, жёлто-оранжевый
4. Удар флиппером → жёлтые частицы разлетаются
5. Отскок от стены/препятствия → голубоватые искры
6. Гол → золотые частицы

## Ожидаемый результат
Мяч выглядит эффектно: свечение, яркий trail, частицы при каждом взаимодействии. Game feel значительно улучшен.
