## Система жизней
- Максимум: 5 жизней
- Восстановление: 1 жизнь каждые 20 минут
- Потеря жизни: проиграл Match или провалил Level
- Endless: жизни не тратятся (нет проигрыша)
- 0 жизней: нельзя начать игру, появляется попап
- Таймер показывает время до следующей жизни

## Настройка в Inspector (LivesManager)
- `Max Lives` — максимум жизней (5)
- `Regen Minutes` — минут на восстановление 1 жизни (20)

## Как тестировать
1. Запусти с MainMenu — жизни отображаются вверху (♥ 5)
2. Best Score под кнопкой Endless
3. Проиграй матч → -1 жизнь
4. Провали уровень → -1 жизнь
5. Когда жизней < 5 → таймер восстановления показывается
6. Когда жизней = 0 → попытка начать игру → попап "NO LIVES!"
7. Для теста: в Inspector на LivesManager поменяй `Regen Minutes` на 0.1 (6 секунд)

## Как сбросить (для тестирования)
Edit → Clear All PlayerPrefs

## Ожидаемый результат
Система жизней с восстановлением по времени. Best Score для Endless в меню. Нельзя играть без жизней.
