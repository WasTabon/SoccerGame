# Iteration 15 — Быстрые флипперы + вратарь-напарник

## Что изменилось с предыдущей итерации
- Обновлён `Flipper.cs` — увеличены дефолтные motorSpeed (3000) и restMotorSpeed (1500)
- Добавлен `DefenseKeeper.cs` — маленький AI-блок между флипперами, следит за мячом, отбивает вверх
- Добавлен editor скрипт `SoccerGameSetup_Iteration15.cs`

## Как настроить
1. Скопируй файлы в проект (заменить Flipper.cs)
2. Открой Game сцену
3. В Unity: меню **SoccerGame → Setup Fast Flippers + Defense Keeper (Iteration 15)**

## Что создаётся/меняется на сцене
- **FlipperLeft / FlipperRight** — motorSpeed увеличен до 3000, maxMotorTorque до 15000
- **DefenseKeeper** — голубой блок между флипперами (y=-9.2), Kinematic, следит за мячом

## Настройка в Inspector

### Флипперы (FlipperLeft / FlipperRight)
- `Motor Speed` — скорость удара (3000)
- `Rest Motor Speed` — скорость возврата (1500)
- `Hit Force Multiplier` — сила импульса мячу (1.5)

### DefenseKeeper
- `Speed` — скорость передвижения (3, медленнее верхнего вратаря)
- `Reaction Delay` — задержка реакции (0.2)
- `Min X / Max X` — ограничение движения (-1 / 1, между флипперами)
- `Deflect Force` — сила отбивания (5, слабее флипперов)

## Как тестировать
1. Нажми Play
2. Флипперы реагируют заметно быстрее
3. Между флипперами — голубой блок, двигается за мячом
4. Он помогает отбивать мяч, но не идеально — можно всё ещё пропустить
5. Мяч отбивается от него вверх

## Ожидаемый результат
Флипперы быстрее реагируют. Между ними — маленький AI-напарник, создающий дополнительную линию защиты.
